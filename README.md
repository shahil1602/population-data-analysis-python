# Population Data Analysis using Python (ABS Dataset)

This project analyses Australian population data across statistical regions using Python to extract insights on demographic distribution and regional variations.

---

## Project Overview

The objective of this project is to process and analyse population data from multiple datasets and identify patterns across different geographic regions.

---

## Key Features

- Data processing and transformation from multiple CSV datasets  
- Mapping hierarchical geographic relationships (SA2 to SA3 levels)  
- Statistical analysis including mean, standard deviation, and correlation  
- Regional population comparison and insights generation  

---

## Tools & Technologies

- Python  
- CSV Data Processing  

---

## Key Insights

- Identified variations in population distribution across regions  
- Compared demographic patterns using statistical measures  
- Analysed relationships between geographic regions  

---

## Files

- `population_analysis.py` – Main Python script for data processing and analysis  

---
